## Release Policy

Changes that may require a release entry include:

- adding or removing a fixture;
- modifying an existing fixture;
- modifying a data contract;
- changing the expected result of a fixture;
- changing generation behavior;
- changing deterministic generation rules;
- modifying fixture checksum values;
- introducing or changing a defect profile;
- making backward-incompatible changes to fixture or manifest formats.

Generated fixture changes should never be treated as insignificant when they
change the expected behavior or checksum of a published artifact.
